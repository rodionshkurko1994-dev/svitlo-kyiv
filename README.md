# Cyber Kyiv

**Сайт:** https://cyber-kyiv.online

3D-карта Києва: які квартали зараз зі світлом, а які без, за плановими графіками відключень YASNO (ДТЕК). Прогноз на 48 годин.

- `index.html` — сама сторінка (three.js).
- `city_v2.txt` — модель міста (будинки з групою YASNO для кожного, вулиці, вода, парки) у base64.
- `schedule.json` — графік YASNO; оновлюється автоматично кожні ~15 хв (`.github/workflows/site.yml`, `scripts/update_schedule.py`).

Це наближення: карта показує планові графіки, а не фактичний стан мережі. Групу кожного будинку взято з YASNO за його адресою (обхід `data/full/`); будинки без адреси отримали групу найближчого сусіда.

Дані карти © учасники OpenStreetMap, ліцензія ODbL. Межі міста — geoBoundaries.

## Групи будинків

`scripts/crawl_groups.py` повільно (≈1 запит/с) запитує в YASNO групу графіка для адрес з OpenStreetMap. Запуск: Actions → «Обхід адрес YASNO» → Run workflow. Результат комітиться в `data/`.

## Щотижневе оновлення груп

`crawl-weekly.yml` запускає повторний обхід усіх частин паралельно; кожна частина після завершення запускає `apply-groups.yml`, який перефарбовує модель (`tools/apply_groups.py`, без OSM: адреси будинків у `data/building_addr.json`) і перепубліковує сайт. Запуск — зовнішнім планувальником (cron-job.org) через API `workflow_dispatch`.

## Громадський транспорт

Трамваї, тролейбуси й автобуси рухаються за розкладом КП «Київпастранс» (GTFS, CC BY 4.0), а не за GPS.
Раз на добу `site.yml` завантажує свіжий розклад і `scripts/build_transit.py` перетворює його на `transit.bin`.
Траси маршрутів у розкладі дуже грубі, тому вони замінюються маршрутами з OpenStreetMap (`data/osm_routes.json`),
а де відповідника немає — прокладаються вулицями й коліями (`data/road_graph.npz`). Обидва файли зібрані з OSM
скриптами `tools/osm_routes.py` і `tools/osm_graph.py`.

## Адмінка

`https://cyber-kyiv.online/admin/` — стан сайту, кнопки запуску оновлень (через GitHub Actions) і оголошення для
відвідувачів (`announcement.json`). Вхід — особистим fine-grained GitHub-токеном із доступом лише до цього
репозиторію (Actions і Contents: Read and write); токен зберігається тільки в браузері адміністратора.

## Погода, час доби й «Мій дім»

Погода береться з Open-Meteo (CC BY 4.0) для поточного часу й погодинно на 48 годин уперед: освітлення карти
відповідає реальному положенню сонця на обраний час, хмарність і туман додають серпанку, дощ і сніг падають
поверх карти, сніг лягає на дахи й землю. «Мій дім» шукає адресу в `addr_index.json` (адреси OpenStreetMap,
зібрані з `data/building_addr.json`) або дає обрати будинок на карті; вибір зберігається лише в браузері.

## Київська агломерація

Будинки, дороги, вода, ліси й адреси навколо Києва (Ірпінь, Буча, Бровари, Бориспіль, Вишгород, Обухів та ін.) беруться з OpenStreetMap.
Workflow `region.yml` (вручну або раз на місяць) завантажує витяг України з Geofabrik, вирізає агломерацію
(`osmium extract -b 29.95,50.05,31.05,50.72`), будує `region/` скриптом `tools/build_region.py` і публікує сайт.
Будинки області завантажуються плитками 8×8 км, коли камера наближається.

Графіки ДТЕК КРЕМ (12 груп) сторінка бере з відкритого набору даних
[Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua) (MIT, `data/kyiv-region.json`, оновлюється
кожні кілька хвилин його власними GitHub Actions). Відкритого списку «адреса → група» для області немає, тому будинки області
забарвлені за часткою груп зі світлом, а в «Мій дім» людина один раз вказує свою групу й бачить точний графік.
