# Світло Києва

**Сайт:** https://svitlo-kyiv.online

3D-карта Києва: які квартали зараз зі світлом, а які без, за плановими графіками відключень YASNO (ДТЕК). Прогноз на 48 годин.

- `index.html` — сама сторінка (three.js).
- `city_v2.txt` — модель міста (будинки з групою YASNO для кожного, вулиці, вода, парки) у base64.
- `schedule.json` — графік YASNO; оновлюється автоматично кожні ~15 хв (`.github/workflows/site.yml`, `scripts/update_schedule.py`).

Це наближення: карта показує планові графіки, а не фактичний стан мережі. Групу кожного будинку взято з YASNO за його адресою (обхід `data/full/`); будинки без адреси отримали групу найближчого сусіда.

Дані карти © учасники OpenStreetMap, ліцензія ODbL. Межі міста — geoBoundaries.

## Групи будинків

`scripts/crawl_groups.py` повільно (≈1 запит/с) запитує в YASNO групу графіка для адрес з OpenStreetMap. Запуск: Actions → «Обхід адрес YASNO» → Run workflow. Результат комітиться в `data/`.

## Щотижневе оновлення груп

`crawl-weekly.yml` запускає повторний обхід усіх частин паралельно; кожна частина після завершення запускає `apply-groups.yml`, який перефарбовує модель (`tools/apply_groups.py`, без OSM: адреси будинків у `data/building_addr.json`) і перепубліковує сайт. Запуск — зовнішнім планувальником (cron-job.org) через API `workflow_dispatch`.
