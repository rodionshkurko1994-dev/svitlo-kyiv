# Світло Києва

3D-карта Києва: які квартали зараз зі світлом, а які без, за плановими графіками відключень YASNO (ДТЕК). Прогноз на 48 годин.

- `index.html` — сама сторінка (three.js).
- `kyiv3d.txt` — модель міста (будинки, вулиці, вода, парки) у base64.
- `schedule.json` — графік YASNO; оновлюється автоматично кожні ~15 хв (`.github/workflows/site.yml`, `scripts/update_schedule.py`).

Це наближення: карта показує планові графіки, а не фактичний стан мережі. Групу кожного будинку визначено за найближчою з 62 опорних адрес, перевірених у YASNO.

Дані карти © учасники OpenStreetMap, ліцензія ODbL. Межі міста — geoBoundaries.
